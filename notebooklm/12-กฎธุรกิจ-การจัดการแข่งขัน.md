# SMASHUP — กฎธุรกิจในโค้ด: ระบบการจัดการแข่งขันและจัดสาย

> เอกสารนี้สรุปจาก `shared/tournament.js` และหน้า `booking/tournament.html` ยืนยันด้วย `tests/tournament.test.cjs` (30 จุดตรวจ)

## 1. โครงสร้างข้อมูล

- Key: `smashup_tournaments_v1` (อาร์เรย์ของรายการแข่ง)
- แต่ละรายการ: `{ id, name, event, status, registrations[], brackets{} , createdAt, startedAt }`
  - `registrations[]`: `{ id, userId, name, level, category, event, status, createdAt }`
  - `brackets[category]`: อาร์เรย์ของรอบ `{ round, name, matches[] }` แต่ละ match `{ id, category, round, position, player1, player2, winnerSlot, score }`

## 2. สถานะของรายการแข่ง

| สถานะ | หมายเหตุ |
|---|---|
| `registration` | เปิดรับสมัคร (เริ่มต้น) — สมัคร/ยกเลิกได้ |
| `in-progress` | จับฉลากจัดสายแล้ว กำลังแข่ง — เก็บผลคู่ต่อคู่ |
| `completed` | รู้ผลชิงชนะเลิศแล้ว → คำนวณอันดับได้ |
| `deleted` | ลบ/ซ่อน (ตัวกรองไม่แสดง) |

## 3. ประเภทและระดับที่รับสมัคร

- `TYPES`, `EVENTS` กำหนดไว้อ้างอิงในระบบ
- สมัครได้ตาม `category` + `event`; ถ้ามีรายการแข่งเดียวกัน `status` ยังไม่ `completed` → **สร้างรายการซ้ำไม่ได้**
- หลัง `status !== 'registration'` → ปิดรับสมัคร (register/cancel ปฏิเสธ)
- เมื่อ `status === 'completed'` → เปิดใหม่/แก้สายไม่ได้

## 4. อัลกอริทึมสร้างสาย (buildBracket) — จัดสายตามระดับมือ

1. **จัดลำดับตามระดับ (seeding):** `rankOf(level)` ให้ค่าตามบันไดระดับ (unknown=0 … A/Pro=9) เรียงมือเก่งสุดเป็นหัวสายก่อน; **สุ่มสลับภายในระดับเดียวกัน** (`shuffle`) เพื่อไม่ให้เดาโครงสาย
2. ตัดผู้สมัครที่ `status === 'cancelled'` ทิ้ง; ต้องการอย่างน้อย **2 คน**
3. **วางหัวสายแบบมาตรฐาน** `seedOrder(n)`: seed #1 อยู่ slot แรก, #2 สุดท้าย, #3 กลางบน, #4 กลางล่าง … → เก่งสุดไม่เจอกันเองจนรอบชิง
4. ขยายเป็น **กำลัง 2 ถัดไป** (`1 << ceil(log2(n))`) และเติม `BYE` (null) ใน slot ว่าง
5. สร้างรอบทั้งหมด `totalRounds = log2(size)` ตั้งชื่อรอบไทย: รอบ 16, รอบก่อนรองชนะเลิศ, รอบรองชนะเลิศ, รอบชิงชนะเลิศ (รอบเล็ก = "รอบ N")
6. รอบแรกกี่ match = `size / 2`; **BYE auto-win ทันที** (`winnerSlot` + score `'BYE'`) และเลื่อนผู้ชนะขึ้นรอบถัดไป (slot คู่→ขึ้นฝั่ง player1, คี่→player2)
7. รอบอื่นยังไม่มีผู้เล่น 2 ฝั่งครบ = รอจับผลเรื่อยๆ

## 5. บันทึกผล (setWinner)

- เลือก `winnerSlot` 1 หรือ 2 + `score` (กรอกผลได้อิสระเป็นข้อความ)
- ตรวจก่อน: สายมีอยู่จริง / รอบ-ตำแหน่งถูก / **ทั้งสองฝั่งต้องมีผู้เล่น** / เลือกฝั่งถูกต้อง
- บันทึกแล้วเลื่อนผู้ชนะขึ้นรอบถัดไปอัตโนมัติ (ตำแหน่งตาม slot)
- เมื่อรอบชิงมีผู้ชนะครบ (`finalRound.matches[0].winnerSlot`) → `status = 'completed'`

## 6. อันดับ 1/2/3 (rankings)

- ผู้ชนะรอบชิง → **อันดับ 1**; ผู้แพ้รอบชิง → **อันดับ 2**
- ผู้แพ้ทั้งสองคู่ของ **รอบรองชนะเลิศ** → **อันดับ 3** (แบ่งอันดับ 3 ร่วมกัน)
- คืนเป็น array `{ rank, id, name, level }` ใช้หน้าแจกเหรียญ/เกียรติบัตร

## 7. ความยุติธรรมของสาย

- **จัดสายตามระดับมือ** (`seedByLevel`): มือเก่งเป็นหัวสายและกระจายคนละทิศ/คนละสาย กันไม่ให้เจอกันเองจนถึงรอบลึก
- การจัดวางใช้ **seedOrder มาตรฐาน** (seed #1↔slot 0, #2↔slot n−1) → มือเก่งสูงสุดสองคนจะพบกันได้แค่รอบชิง
- ผู้เล่นระดับเดียวกันถูก **สุ่มสลับ** ดังนั้นสายยังมีความไม่แน่นอน ไม่เปิดเผยโครงสายทั้งหมดล่วงหน้า
- BYE เป็นอัตโนมัติ ไม่ต้องแข่ง; ผู้ชนะค่อยๆ เลื่อนมาบรรจบกันที่รอบชิง
