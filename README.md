# SMASHUP Badminton Project

เว็บไซต์ต้นแบบสำหรับจองสนามแบดมินตันและหาคู่เล่นภายใต้ชื่อ **SMASHUP** ออกแบบให้ใช้งานง่ายบนมือถือและเดสก์ท็อป ด้วยโทนสีส้ม ดำ และขาว

## ฟีเจอร์

- หน้าแรกสำหรับแนะนำสนาม จุดเด่น ภาพบรรยากาศ กติกา และโปรโมชัน
- หน้าที่สองสำหรับรวมบริการและหัวข้อทั้งหมด
- เมนูหัวข้อบนมือถือแบบ drawer สีน้ำเงิน
- ฟอร์มจองสนามที่เลือกวันที่ เวลา จำนวนคอร์ต ชื่อ และเบอร์โทรศัพท์
- คำนวณค่าบริการโดยประมาณอัตโนมัติที่ 130 บาทต่อคอร์ตต่อชั่วโมง
- แสดงข้อความยืนยันหลังส่งแบบฟอร์ม
- Responsive รองรับหน้าจอมือถือ แท็บเล็ต และเดสก์ท็อป

## โครงสร้างไฟล์

```text
.
├── index.html          # entry point และหน้าแรก
├── home/
│   └── home.css        # สไตล์เฉพาะหน้าแรก
├── booking/
│   ├── index.html      # หน้าหลัก Feature จองสนามและ sidebar
│   ├── form.html       # หน้าฟอร์มและตารางคอร์ตแบบเต็ม
│   ├── booking.css     # สไตล์หน้าหลักจองสนาม
│   ├── booking.js      # logic ของฟอร์มจองสนาม
│   ├── topic.css       # สไตล์ร่วมของหน้า topic
│   ├── rules.html      # กฎการใช้สนาม
│   ├── booking-info.html
│   ├── buffet-booking.html
│   ├── buffet-info.html
│   ├── buffet-queue.html
│   ├── tournament.html
│   ├── practice.html
│   └── shop.html
```

## วิธีเปิดใช้งาน

โปรเจกต์นี้เป็น static website ไม่ต้องติดตั้ง package เพิ่มเติม

### เปิดด้วยเว็บเบราว์เซอร์โดยตรง

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้เลย หน้าแรกจะลิงก์ไปยัง `booking/index.html`

### เปิดผ่าน local server

หากต้องการทดสอบเหมือนการใช้งานจริง ให้รันคำสั่งจากโฟลเดอร์โปรเจกต์:

```bash
python -m http.server 4173
```

จากนั้นเปิด <http://localhost:4173/>

## การใช้งาน

1. หน้าแรกจะแสดงข้อมูลและโปรโมชันของสนาม
2. กดปุ่ม **จองสนาม** เพื่อเข้าสู่หน้า Feature ที่แยกไว้ในโฟลเดอร์ `booking/`
3. กดหัวข้อจาก sidebar เพื่อเปิดหน้าแยก หรือกดจองสนามแบดมินตันเพื่อเปิด `booking/form.html`
4. หลังยืนยัน ระบบจะแสดงรายละเอียดการจองบนหน้าเว็บ

> ข้อมูลการจองในเวอร์ชันนี้เป็นการจำลองฝั่งหน้าบ้าน ยังไม่ได้เชื่อมต่อฐานข้อมูลหรือระบบแจ้งเตือนจริง

## การปรับแต่ง

- แก้เนื้อหาและลิงก์หน้าแรกได้ใน `index.html`
- แก้สี ฟอนต์ และ responsive ของหน้าแรกได้ใน `home/home.css`
- แก้หน้าและฟอร์มจองสนามได้ใน `booking/index.html`
- แก้สไตล์และพฤติกรรมฟอร์มได้ใน `booking/booking.css` และ `booking/booking.js`
- หน้าเนื้อหาแต่ละหัวข้อใช้ไฟล์ HTML แยกใน `booking/` และใช้ `booking/topic.css` ร่วมกัน
- ภาพสนามและฟอนต์โหลดจาก Google Fonts และ Unsplash จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อให้แสดงผลครบถ้วน
